# gks_analysis_2425
In-depth study of La Liga GKs from 24/25 season.

In this project from my Masters degree in Big Data Applied to Sports, I took an extra step into one of my tasks from Module 2.

With data from FBRef and using Fotmob as my backup website for extra info, I analysed the Goalkeepers from LaLiga 24/25 competition.

Using Databricks and PySpark, as intended in the original task, I go through all the ETL process and in the end I also created an algorithm to predict the best goalkeeper in that season.

All the code is available to download for everyone in this repo.

Just a little disclaimer, this is an educative project, all suggestions and help is helpful.

I trully hope you enjoy the content!
